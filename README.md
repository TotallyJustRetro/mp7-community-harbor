# MP7 Community Harbor

Unofficial fan-made community hub for the Mario Party 7 recomp project.

## Current release: static preview

This repository contains a static HTML/CSS/JavaScript website. Sample boards, mods, minigames, and discussions are illustrative entries, not real uploads. Sign-in, publishing, downloads, ratings, and discussions are intentionally disabled until a backend and moderation/privacy process are ready.

## Publish for free with GitHub Pages

This repository is public, so GitHub Free can host it with GitHub Pages:

1. Open **Settings** in this repository.
2. Choose **Pages** under **Code and automation**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. GitHub will show the published address in the Pages section. The expected project-site URL is `https://totallyjustretro.github.io/mp7-community-harbor/`.

Every update pushed to `main` will be published automatically. See [GitHub's official guide](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Local preview

Open `index.html` in a modern browser. No build tools are required.

## Planned backend

Supabase may be added later for authentication, board metadata, private file storage, approvals, and reports. Do not add private keys or passwords to this public repository. Never put a Supabase service-role key in a browser file.

Before enabling public accounts or user uploads, the site operator should have a trusted adult review provider terms, age requirements, privacy notices, moderation coverage, file validation, and deletion/report processes. Public submissions should remain private until reviewed.

## Safety and project status

- Do not upload ROMs, game executables, copyrighted game assets, malware, or content you do not have permission to redistribute.
- Uploaded packages should be restricted to approved formats and size limits, scanned and validated server-side, and reviewed before publication.
- This site is unofficial and is not affiliated with, endorsed by, or sponsored by Nintendo.
- The Board Maker, online multiplayer, creator profiles, mods repository, and minigame downloads are roadmap concepts, not implemented services.
