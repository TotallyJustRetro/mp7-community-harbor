# Free hosting with GitHub Pages

This is a plain static website, so it does not need a paid server or build step.

1. Open the repository on GitHub and click **Settings**.
2. In the left sidebar, open **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose **main** as the branch and **/(root)** as the folder.
5. Click **Save**.
6. Return to the Pages settings after deployment finishes and open the published site link.

GitHub Pages supports public repositories on GitHub Free. The website is public. Keep credentials, passwords, API secrets, and personal data out of this repository. For the official instructions, see https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site.
